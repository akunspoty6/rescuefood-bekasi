## ⚡ Cara Menjalankan di Lokal (Quick Run)

### Opsi A: Langsung Buka File
Cukup klik ganda file `index.html` di komputer/laptop Anda, atau buka via browser (Chrome, Edge, Safari).

### Opsi B: Menggunakan Local Web Server (Direkomendasikan)
Buka terminal di folder ini dan jalankan salah satu perintah berikut:
```bash
# Menggunakan Python 3:
python3 -m http.server 8000

# Menggunakan Node.js / npx:
npx serve .
```
Lalu buka browser Anda di: `http://localhost:8000`
